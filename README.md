Moon Loop — an original digital painting of a roller-coaster track looping through a giant glowing golden full moon under an indigo night sky, made to make the AI judge excited. The entry program copies `entry.png` to the grader's output directory, byte for byte, so re-running it always yields the exact same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
